# Penalty Family PRO v2

نسخه حرفه‌ای بازی بابا علی و سپنتا.

## امکانات جدید
- دو حالت «حرفه‌ای» و «فان»
- شوت حرفه‌ای بر اساس سرعت و طول سوایپ
- تعیین ارتفاع توپ با حرکت رو به بالا
- کات چپ/راست بر اساس قوس مسیر انگشت
- تشخیص شوت محکم، بغل‌پا، کات‌دار و چیپ
- شش جهت شیرجه دروازه‌بان
- تأثیر زمان واکنش دروازه‌بان بر شانس سیو
- شوت بیرون، بالای دروازه و برخورد به تیر
- انیمیشن مسیر توپ با کات و چرخش
- لرزش در دستگاه‌های پشتیبانی‌شده
- پنج پنالتی برای هر نفر و گل طلایی در تساوی

## نصب روی Netlify با گوشی
فایل ZIP را در Netlify Drop آپلود کنید. `index.html` در ریشه فایل ZIP قرار دارد و نیازی به build نیست.
